Language Learning with YouTube

April 20, 2024

This interactive web application allows users to learn a new language through YouTube videos with synchronized subtitles. It highlights unknown words, provides definitions on hover, and enables users to save and track their learning progress for easy integration into flashcard apps.

What I accomplished:

  • Integrated YouTube's iframe API to sync video playback with subtitles.
  • Developed a script parser to process SRT subtitle files.
  • Engineered a module that identifies root words and retrieves definitions from a JSON file of the Wiktionary database, improving language learning functionality.
  • Implemented a feature to highlight unknown words and allow users to download personalized vocabulary files for direct Anki flashcard app integration, greatly improving the learning workflow.
