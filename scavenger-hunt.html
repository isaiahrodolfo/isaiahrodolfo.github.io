Scavenger Hunt

March 19, 2025

GitHub

A fast-paced, interactive game where players race to snap pictures of given items. Utilizing real-time communication, the game syncs actions across players while moderators approve or deny photo submissions, declaring the winner. Players engage in a fun, competitive experience to capture the most items, with the game seamlessly integrated with device hardware for a smooth user experience.

What I accomplished:

  • Integrated Socket.io for real-time communication, ensuring seamless synchronization of game logic and player actions in the cloud, enhancing the game to create a multiplayer experience.
  • Leveraged the Expo API to enable device camera access, enabling players to capture and submit photos directly through the application.
  • Developed and implemented efficient moderation tools, allowing for fair gameplay, smooth photo approval and real-time game updates.
